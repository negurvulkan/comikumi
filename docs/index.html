Lettering & typesetting for manga and comics — on your own machine

ComiKumi is a self-hosted web app for placing and translating speech bubbles, curved titles, and image patches directly on scanned comic pages, and exporting the result as ready-to-publish pages.

Features

Everything a lettering team needs

From multi-language bubbles to full vertical Japanese typesetting.

Multi-language lettering

Every text and style field on a bubble can be overridden per language, or fall back to a shared base value. Add as many languages as your project needs.

Full vertical Japanese typesetting

Tategaki with forced line breaks, group- and mono-ruby furigana, bōten emphasis dots, automatic tate-chū-yoko for digit/Latin runs, and kinsoku shori line-breaking rules.

Four element types

Speech bubbles (rectangle, oval, or free perspective quad), placed images, curved title/SFX text along a Bézier path, and panel-reference polygons.

Clip & merge bubbles

Cut a bubble along a straight line so it sits flush against a panel edge, or non-destructively merge several bubbles into one continuous outline for dialogue that flows across them.

Layers & panel locking

A navigator lists every bubble, image, and curved text grouped by panel, each with its own lock toggle — plus one-click "lock all panels" and "lock panel + its bubbles" so overlapping panels stop getting in the way of what's underneath.

Lettering presets

Reusable styles that live-update every linked bubble or curved text, field by field, without overwriting values a preset doesn't define — or start from a built-in library (Manga SFX, Whisper, Shout).

Context view & glossary

A reading-order-aware sidebar with speaker, voice notes, and panel crop, plus a project glossary with live highlighting and optional furigana readings.

AI assistant

Ask-only chat backed by your own OpenAI key or a ChatGPT sign-in — grounded in the current page's dialogue and artwork, or the script during planning.

Script planning

A volume-wide script editor for plot, panel layout, and per-language dialogue — link it to a real page and insert dialogue with one click.

Project asset folders

Fonts, SVG bubble contours, and images live in a shared library, a per-project folder, or both — the project version wins on a filename collision.

PNG, print, vector & CBZ export

Export ready-to-publish PNGs, CMYK TIFFs for print, vector PDF/PSD with editable text, or CBZ with full ComicInfo.xml metadata — plus JSON import/export for a whole volume's layouts.

Review & QC comments

Pin, box, or freehand comments anywhere on a page, with @-mentions of specific accounts or roles — plus optional email notifications so feedback reaches the right person.

Read/Review viewer

A dedicated, distraction-free reading screen for QC passes: zoom-to-panel, reading-direction-aware page turning, double-page spreads, and side-by-side comparison of up to four pages.

Deploy anywhere

Run it solo on your machine, share it on your studio's network, or host it on a server reachable over the internet — role-based accounts keep it safe either way.

How it works

Your data stays under your control

  • ✓
    No forced cloud, no telemetry

    A small Express server reads and writes files on disk — yours. Run it solo on your laptop, shared on your studio's network, or on a server reachable over the internet; nothing is ever sent to a third party.

  • ✓
    One file per project

    A project is a single JSON file — languages, characters, glossary, presets, and settings — next to your existing folder of scanned pages.

  • ✓
    Role-based access

    Viewer, translator, letterer, and admin roles per project, so a team can safely share one server — on a local network or over the internet.

  • ✓
    Free and open source

    AGPL-3.0-licensed. Use it, study it, modify it, self-host it for your team.
